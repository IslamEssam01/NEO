# NEO - Eye Tracking Project

## Overview
NEO is an eye-tracking project that leverages computer vision techniques to monitor and analyze eye movements. This project is designed to help with various applications such as user attention tracking, drowsiness detection, and more.

## Features
- Real-time eye tracking
- Head pose estimation
- Drowsiness detection with an alarm system

## Requirements
To run this project, you'll need:
- Python 3.x
- Required libraries listed in `requirements.txt`

Install the required libraries using:
```bash
pip install -r requirements.txt
```

## Files
- `NEO.py`: Main script for running the project
- `eye.py`, `gaze.py`, `headPose.py`: Modules for eye tracking and head pose estimation
- `model.pkl`: Pre-trained model for eye tracking
- `alarm.mp3`: Audio file for the drowsiness alarm

## Usage
Run the main script using:
```bash
python NEO.py
```
